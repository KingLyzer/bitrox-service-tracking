Bitrox ServiceTracker Kurulum ve Yapılandırma Kılavuzu

Bu dokümantasyon, Bitrox ServiceTracker uygulamasının yerel geliştirme veya canlı Linux/Windows sunucu ortamında sıfırdan kurulması, MySQL veritabanı ayarları ve Snipe-IT REST API entegrasyonu için gerekli tüm adımları içerir.

1. Sistem Gereksinimleri

  • Node.js: v18.0.0 veya üzeri (LTS sürümü önerilir)
  • MySQL / MariaDB: v8.0 veya üzeri (InnoDB motoru ve utf8mb4 karakter seti ile)
  • npm veya yarn paket yöneticisi
  • Git: Depoyu klonlamak için
  • (İsteğe Bağlı) Snipe-IT v5.0+ (API erişimi etkinleştirilmiş) — Snipe-IT olmadan da tüm modüller yerel veritabanıyla bağımsız çalışır.

2. Hızlı Kurulum (5 Basit Adım)

Adım 1: Depoyu Klonlayın

git clone https://github.com/KingLyzer/bitrox-service-tracking.git
cd bitrox-service-tracking

Adım 2: Bağımlılıkları Yükleyin

npm install

Adım 3: Temiz Veritabanını Oluşturun

Proje kök dizininde hazır bulunan database_schema.sql dosyasını MySQL sunucunuzda çalıştırın. Bu dosya servicetracker_db tablosunu, başlangıç rollerini ve varsayılan yönetici hesabını oluşturur:

mysql -u root -p < database_schema.sql

Adım 4: .env Dosyasını Yapılandırın

Kök dizindeki .env.example dosyasını kopyalayarak .env adıyla kaydedin ve veritabanı parolanızı yazın:

cp .env.example .env

Adım 5: Arayüzü Derleyin ve Sunucuyu Başlatın

npm run build
npm start

Uygulama varsayılan olarak http://localhost:9999 portunda yayına girecektir.

Önemli: Varsayılan giriş bilgileri: Kullanıcı Adı: admin / Şifre: admin123. Giriş yaptıktan sonra şifrenizi Ayarlar sayfasından değiştiriniz.

3. Snipe-IT API Entegrasyonu

ServiceTracker'ın personel zimmetli cihazları ve yazıcıları otomatik listelemesi için Snipe-IT bağlantısını tanımlayın:

  1. Snipe-IT yönetim panelinize girin: Yönetici → API Anahtarlarını Yönet (Manage API Keys) sekmesine gidin.
  2. Yeni bir API Token (Bearer Token) oluşturun ve anahtarı kopyalayın.
  3. ServiceTracker arayüzünde Ayarlar → Genel Ayarlar → Snipe-IT Entegrasyonu bölümüne gelin:
    • Snipe-IT URL: https://envanter.sirketiniz.com
    • API Token: Kopyaladığınız token'ı yapıştırın.
  4. Kaydet butonuna basın. Arka planda senkronizasyon motoru devreye girecek ve kullanıcı/cihaz listesini yerel MySQL önbellek tablosuna aktaracaktır.

4. PM2 ile Canlı Sunucu Dağıtımı

Sunucunuz yeniden başladığında uygulamanın kesintisiz çalışması için PM2 önerilir:

npm install -g pm2
pm2 start server/server.js --name "servicetracker"
pm2 save
pm2 startup
