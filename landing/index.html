Neden Snipe-IT Entegrasyonu Kritik?

Snipe-IT dünyanın en popüler demirbaş yönetim yazılımıdır, ancak saha operasyonlarında arıza fişi takibi, yazıcı toner sayaçları, kargo lojistiği ve periyodik bakım tutanağı gibi süreçleri barındırmaz. Bitrox ServiceTracker, Snipe-IT'nin üzerine kurulan mükemmel bir IT Servis Masası (Service Desk) katmanıdır.

Hemen Kurun ve Kullanmaya Başlayın

Tek bir Linux veya Windows sunucuda 5 basit komut ile kuruluma hazır.

bash — bitrox-service-tracking install
# 1. Proje reposunu GitHub üzerinden klonlayın
git clone https://github.com/KingLyzer/bitrox-service-tracking.git && cd bitrox-service-tracking
# 2. Gerekli tüm bağımlılıkları indirin
npm install
# 3. Temiz veritabanı şemasını ve tabloları oluşturun
mysql -u root -p < database_schema.sql
# 4. Çevre değişkenini yapılandırın (.env dosyasına veritabanı şifrenizi yazın)
cp .env.example .env
# 5. Arayüzü derleyin ve sunucuyu başlatın!
npm run build && npm start
Varsayılan Giriş Bilgileri: Kullanıcı Adı: admin / Şifre: admin123
Port: 9999
