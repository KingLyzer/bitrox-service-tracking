Problem ve Çözüm

Dağınık IT Süreçlerini Tek Masada Toplayın

Kurumsal BT ekipleri demirbaş sayımını Snipe-IT ile çözebilse de arıza kabulü, toner sayaç logları ve resmi bakım tutanakları genellikle kağıt veya Excel tablolarına dağılır.

Geleneksel Dağınık Yöntem
  • Arıza bildirimleri telefon, e-posta ve sözlü taleplerle gelir; kayıtlar unutulur veya kaybolur.
  • Toner değişimleri Excel dosyalarında tutulur, hangi yazıcının kaç sayfa yazdırdığı hesaplanamaz.
  • Şubelere giden kargolar kurye takip ekranlarında kaybolur, arıza fişiyle doğrudan ilişkilendirilemez.
  • Yıllık donanım bakımlarında kimin hangi adımı kontrol ettiği belgelenemez; denetimlerde tutanak bulunamaz.
Bitrox ServiceTracker Yaklaşımı
  • Personel seçildiği anda zimmetli cihazı otomatik gelir; 5 aşamalı onarım iş akışıyla takip edilir.
  • Yazıcı sayaç (sayfa adedi) ve CMYK renk takibi yapılır; kritik stok seviyesinde sistem otomatik uyarır.
  • Gelen ve giden kargolar tek tıkla standart 100x150 mm termal barkod koli etiketine dönüştürülür.
  • 9 zorunlu adımlı periyodik bakım protokolü uygulanır ve işletme müdürü imzalı resmi tutanak üretilir.
Uygulama İçi Akışlar

Saha Teknisyenleri İçin Tasarlanan 4 Temel Süreç

Gereksiz tıklamaları ve veri tekrarını ortadan kaldıran pratik iş akışları.

1. Teknik Servis & Arıza Fişi Akışı

Barkod okutarak veya seri numarası girerek cihaz kabulü yapın. Kullanılan yedek parçaları (SSD, RAM vb.) depodan düşerek fişe ekleyin ve onarım maliyetini net olarak görün.

  • 1Hızlı kabul: Seri no, arıza şikayeti ve teslim eden personel kaydı
  • 2Aşamalı durum: Yeni, Onarımda, Parça Bekliyor, Dış Servis, Teslim
  • 3Maliyet takibi: Değişen parçalar ve işçilik bedeli dökümü
https://servicetracker.local:9999/service-tickets

2. Yazıcı Sayaç & Toner Sarfiyatı

Yazıcıların sadece stok sayısını değil, her toner değişimindeki sayfa sayacını kaydedin. Bir tonerin kaç sayfa yazdırdığını ve birimlerin tüketim oranlarını analiz edin.

  • 1Model ve renk bazlı depo eşikleri (Siyah, Cyan, Magenta, Yellow)
  • 2Değişim esnasında yazıcı sayaç (sayfa adedi) kaydı
  • 3Kritik stok uyarısı ile tükenmeden önce satın alma planı
https://servicetracker.local:9999/toner-tracking

3. Master Operasyon Takvimi & Planlama

Tüm teknik servis fişlerini, periyodik donanım bakımlarını, kargo hareketlerini ve toner teslimatlarını tek merkezi ajandada renk kodlarıyla izleyin.

  • 1Servis, periyodik bakım, kargo ve sarf malzeme hareketleri tek takvimde
  • 2Tarihe tıklandığında ilgili fiş detayını doğrudan çağırma
  • 3Geciken ve yaklaşan servisler için görsel takvim işaretçileri
https://servicetracker.local:9999/calendar

4. Islak İmzalı PDF ve Termal Kargo Etiketi

Hem yasal teslim-tesellüm formları hem de kargo lojistik operasyonları için standart çıktı şablonları. Harici etiket tasarım programlarına ihtiyaç duymaz.

  • 1Teknisyen ve teslim alan imza alanlı kurumsal PDF fiş dökümü
  • 2100x150 mm termal barkodlu kargo koli etiketi
  • 39 adımlı periyodik donanım bakım onay tutanağı
Resmi Belge & Etiket Önizleme Standart PDF / 100x150mm
Belge Türü: Donanım Teslim-Tesellüm Tutanağı
Format: Vektörel PDF (Islak İmza Alanları Dahil)

Kurulum Kılavuzu

Kendi Sunucunuzda Dakikalar İçinde Başlatın

Ön koşullar: Node.js (v18.0+) ve MySQL / MariaDB (8.0+). Dilediğiniz dağıtım yöntemini seçin.

bash — bitrox-service-tracking 
# 1. Depoyu GitHub'dan klonlayın
git clone https://github.com/KingLyzer/bitrox-service-tracking.git
cd bitrox-service-tracking

# 2. Bağımlılıkları yükleyin
npm install

# 3. Temiz MySQL veritabanı şemasını kurun
mysql -u root -p < database_schema.sql

# 4. Çevre değişkenini yapılandırın (.env dosyasına DB şifrenizi yazın)
cp .env.example .env

# 5. Arayüzü derleyin ve sunucuyu başlatın
npm run build
npm start
# 1. PowerShell ile depoyu indirin
git clone https://github.com/KingLyzer/bitrox-service-tracking.git
Set-Location bitrox-service-tracking

# 2. Bağımlılıkları yükleyin
npm install

# 3. .env oluşturun ve başlatın
Copy-Item .env.example .env
npm run build
npm start
# 1. PM2 kurulu değilse kurun
npm install -g pm2

# 2. ServiceTracker uygulamasını arka planda başlatın
pm2 start server/server.js --name "servicetracker"

# 3. Sunucu yeniden başladığında otomatik çalışması için kaydedin
pm2 save
pm2 startup
Güvenlik Uyarısı: Varsayılan giriş bilgileri Kullanıcı Adı: admin / Şifre: admin123 olarak gelir. Sisteme ilk girişinizden hemen sonra Ayarlar → Kullanıcı Yönetimi sekmesinden şifrenizi mutlaka değiştiriniz.
Güvenlik ve Veri Sahipliği

Verileriniz Tamamen Kendi Sunucunuzda Kalır

Üçüncü taraf bulut sağlayıcılarına bağımlılık yok. Kurumsal gizlilik prensipleriniz kendi altyapınızda korunur.

%100 Self-Hosted

Yazılım kendi yerel ağınızda (LAN), şirket sunucunuzda veya kendi VPS sunucunuzda çalışır. Dışarıya telemetri verisi gönderilmez.

Bcrypt Şifreleme

Tüm kullanıcı parolaları endüstri standardı tek yönlü Bcrypt algoritması ile hashlenerek saklanır; düz metin olarak depolanmaz.

Rol & Yetki Matrisi

Super Admin, Admin, Teknisyen ve Kullanıcı rolleri için modül bazında okuma, yazma ve silme yetkileri tam denetim altındadır.

Bearer Token İletişimi

Snipe-IT ile haberleşme salt-okunur Bearer Token yetkilendirmesiyle yapılır; veritabanı doğrudan dışa açılmaz.
