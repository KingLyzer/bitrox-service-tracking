1. Tipografi & Hiyerarşi

Plus Jakarta Sans (Gövde ve Başlıklar) + JetBrains Mono (Kod & Monospace). Türkçe karakter tam uyumu: ğ ü ş ı ö ç İ.

Display H1 — Kurumsal IT Servis Masası (52px)

Heading H2 — 21 Eksiksiz Modül ve Saha Akışı (32px)

Heading H3 — Snipe-IT Salt-Okunur API Mimarisi (24px)

Gövde Metni (15px) — Arıza fişleri, yazıcı sayaç takibi, BitLocker anahtar kasası ve bakım tutanaklarını tek merkezde toplayan açık kaynaklı IT operasyon portalı.

git clone https://github.com/KingLyzer/bitrox-service-tracking.git

2. Renk Paleti (Tokens)

Açık ve koyu temalara uyumlu semantik renk token'ları. Neon ve parıltıdan uzak, sakin kurumsal tonlar.

--accent
Vurgu Rengi
--bg-base
Arka Plan
--bg-surface
Yüzey / Kart
--success
Tam / Başarılı
--warning
Temel / Uyarı

3. Butonlar (3 Varyant)

Birincil (Primary), İkincil (Secondary) ve Hayalet (Ghost) buton varyantları + ikon butonları.

4. Rozetler (Badges)

Sürüm, lisans ve durum etiketleri.

v2.3.2 Production Açık Kaynak (MIT) Self-Hosted Tam (Yerleşik) Temel Destek Kapsam Dışı

5. Uyarı Kutuları (Callouts)

Yönetici şifresi değişikliği ve sistem güvenlik uyarıları.

Güvenlik Uyarısı (Zorunlu Şifre Değişimi): Varsayılan giriş bilgileri admin / admin123 olarak tanımlıdır. İlk girişte şifrenizi Ayarlar sayfasından değiştiriniz.

6. Kod Bloğu Penceresi

Terminal komutları için kopyalama butonlu pencere.

bash — servis kurulumu 
git clone https://github.com/KingLyzer/bitrox-service-tracking.git
cd bitrox-service-tracking
npm install
npm run build && npm start

7. Adil Karşılaştırma Tablosu

Dürüst ve ölçekli karşılaştırma stili.

Fonksiyonel Yetkinlik Tek Başına Snipe-IT ServiceTracker + Snipe-IT
IT Demirbaş & Varlık Yönetimi Tam (Yerleşik) Tam (API ile Senkron)

8. Akordiyon (SSS Bileşeni)

Erişilebilir, klavye odaklı akordiyon.

Evet. Snipe-IT entegrasyonu tamamen isteğe bağlıdır. Tüm servis, toner, stok ve bakım modülleri bağımsız olarak yerel veritabanınızda çalışır.
