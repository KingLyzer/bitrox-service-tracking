Problem & Solution

Replace Scattered Tools with a Unified Desk

While Snipe-IT excels at asset counting, field repair tickets, toner page counters, and signed protocols frequently end up fragmented in spreadsheets.

Traditional Disjointed Setup
  • Hardware failure reports arrive through phone calls, sticky notes, and random emails; audit trails get lost.
  • Toner changes logged in spreadsheets without printer page counters, making page yield calculation impossible.
  • Branch courier shipments are disconnected from tickets, requiring manual carrier portal checks.
Bitrox ServiceTracker Workflow
  • Selecting an employee instantly lists their assigned Snipe-IT devices with a structured 5-stage repair workflow.
  • Printer counter (page volume) and CMYK stock levels tracked with automated threshold reorder alerts.
  • Inbound and outbound shipments linked to tickets, generating standard 100x150 mm thermal shipping barcodes.

Quick Start

Deploy in Minutes

Prerequisites: Node.js (v18.0+) and MySQL / MariaDB (8.0+).

bash — bitrox-service-tracking 
# 1. Clone repository
git clone https://github.com/KingLyzer/bitrox-service-tracking.git
cd bitrox-service-tracking

# 2. Install dependencies
npm install

# 3. Create database tables
mysql -u root -p < database_schema.sql

# 4. Configure environment
cp .env.example .env

# 5. Build assets and launch
npm run build
npm start
